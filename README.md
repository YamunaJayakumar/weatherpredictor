# Real-Time Weather App 🌤️

A **real-time weather app** built with **HTML, CSS, JavaScript, and Bootstrap** 

The app allows users to search for a city and view live weather data including temperature, humidity, pressure, and weather conditions with a modern, responsive UI.

---

## Features

- Search for cities by name  
- Display live weather data:
  - Temperature (°C)  
  - Humidity (%)  
  - Pressure (hPa)  
  - Weather conditions with icons  
- Clean, responsive UI using **Bootstrap** and **CSS glassmorphism effects**  
- Error handling for invalid city names  

---

## Technologies Used

- HTML5  
- CSS3 (with glassmorphism effects)  
- JavaScript (async/await, DOM manipulation)  
- Bootstrap 5  
- Font Awesome icons  
- OpenWeatherMap API
